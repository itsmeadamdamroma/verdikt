Quick answers

  

  

    
How is this different from asking ChatGPT?
LLMs generate plausible text. Verdikt runs a decision model on retrieved evidence and returns calibrated probabilities with sources, and labels unverifiable claims instead of guessing.

    
What languages are supported?
Claims in English and Italian today; transcription supports 90+ languages via faster-whisper. Evidence retrieval falls back to English sources when local ones are thin.

    
What do the 4 verdicts mean?
true: evidence supports it. false: evidence contradicts it. misleading: partially true but distorted. unverifiable: not enough independent evidence; we never guess.

    
Do you store my audio?
No. Audio is transcribed in a temp file that is deleted immediately after processing; only aggregated usage counters are kept.
